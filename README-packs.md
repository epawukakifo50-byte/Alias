# Как создавать и редактировать наборы слов ✏️

Все тематические наборы хранятся в формате JSON в директории приложения. Вы можете легко изменить существующие или добавить новые.

## 📂 Расположение файлов
Файлы находятся в папке `src/data/packs`. 

## 📝 Редактирование существующего набора
Чтобы изменить, например, стандартный набор (или набор "Видеоигры"):
1. Откройте панель файлов (слева) и раскройте папку `src` → `data` → `packs`.
2. Кликните на файл `games.json` или `standard.json`.
3. В структуре вы увидите массив `"words"`. Просто допишите нужные слова в кавычках через запятую.
   *Пример:*
   ```json
   "words": [
     "Геймпад",
     "Консоль",
     "Новое слово"
   ]
   ```

## ➕ Как добавить свой собственный набор
Если вы хотите полностью новый набор, нужно сделать две вещи:
1. Создать новый файл (например, `movies.json`) в папке `src/data/packs` по аналогии с другими:
   ```json
   {
     "id": "movies",
     "name": "Кино",
     "words": ["Оскар", "Режиссер", "Камера", "Голливуд"]
   }
   ```
2. Подключить этот файл в меню игры:
   - Откройте `src/data/packs/index.ts`
   - Добавьте импорт: `import movies from './movies.json';`
   - Добавьте его в список `packs`:
     ```ts
     export const packs: Record<string, WordPack> = {
       standard,
       hard,
       games,
       movies
     };
     ```
   - Зайдите в `src/components/SetupScreens.tsx` (начиная со строки ~380) и добавьте новую кнопку для этого `packId`.

*Если запутаетесь — просто попросите ИИ-ассистента добавить набор, передав ему список тем!*
